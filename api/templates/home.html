FIRST FIVE MINUTES

Generate a signal. Follow the evidence.

  1. Run a simulation on your host

    From the project directory, with dependencies installed:

    python -m network_security_monitor --simulate --no-dashboard

    The simulation writes alert and incident artifacts on that host. The web app reads them when it uses the same configured storage paths.

    Open the overview, filter by severity, and inspect an alert’s evidence.
